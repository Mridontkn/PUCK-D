# City hat preview photos

Put all 341 city/colour product photos in this folder. The designer expects one PNG per variation, named:

`<city-slug>-<colour-slug>.png`

Examples:

- `anaheim-black.png`
- `calgary-navy.png`
- `washington-dc-light-blue.png`
- `st-louis-spruce-green.png`

Use lowercase names and replace spaces and punctuation with hyphens. Each photo should show the finished hat variation, including its city lettering. Missing photos display a colour-matched placeholder and the expected filename in the designer.
